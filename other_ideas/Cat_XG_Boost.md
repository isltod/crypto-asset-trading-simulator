## CatBoost + XGBoost 기반 코인 시계열 트레이딩 시스템 명세서
이 문서는 대규모 트랜스포머(TSFM) 모델의 실전 매매 한계(거래 비용 및 과적합 문제)를 극복하고, 개인 PC 환경에서 AI 코딩 에이전트의 도움을 받아 안정적인 우상향 수익을 모델링할 수 있는 트리 기반 머신러닝 앙상블 트레이딩 시스템의 구조를 정의합니다.
------------------------------
## 1. CatBoost + XGBoost 조합의 개념과 강점
전통적인 퀀트의 단순 조건문(예: RSI < 30 이면 매수) 전략은 가짜 신호와 하락 추세에서의 물타기로 인해 장기 백테스트 시 무조건 손실을 기록합니다. 반면, 성향이 다른 두 베테랑 모델을 결합한 앙상블(Ensemble) 방식은 고차원적 맥락을 분석하여 이를 극복합니다.

* 
* XGBoost (수치 타격 전문가): 거래량 변화, 지표의 미세한 수치적 꺾임 등 연속적인 기술적 지표의 변화를 날카롭게 포착하여 가격 상승/하락의 확률을 계산합니다.
* CatBoost (범주/상태 분석 전문가): 현재 요일, 시간대, 현재 장세가 불장인가 횡보장인가 등 시장의 환경과 조건(Categorical Feature)을 완벽하게 분류하고 결합하여 예측 능력을 극대화합니다.
* 핵심 차별점 (비선형 맥락 파악): "RSI가 30 이하"라는 단일 조건만 보지 않고, "RSI가 30 이하이면서 동시에 변동성(ATR)이 낮고 거래량이 터지는 맥락"을 통계적 확률 점수(0%~100%)로 변환합니다. 최종 합산 확률이 설정한 기준치(예: 70%)를 넘을 때만 진입하므로 시장의 가짜 신호(노이즈)를 압도적으로 잘 걸러냅니다.
* 

------------------------------
## 2. 시스템 구현 파이프라인 (Data & Execution Flow)
일반 가정용 PC 환경의 CPU 연산만으로도 수 초~수 분 내에 학습과 예측이 완료되는 가볍고 빠른 파이프라인입니다. AI 코딩 에이전트(안티그래비티, 커서 등)에게 아래 4단계 흐름을 기반으로 코드를 요청합니다.

[1단계: 데이터 수집] ➡️ [2단계: 데이터 가공] ➡️ [3단계: 앙상블 학습] ➡️ [4단계: 실시간 매매]
 바이낸스/업비트 API     변화율 및 6대 지표       XGB + CatBoost       1시간마다 예측 수행
 (과거 3년 1H 봉)        타임 윈도우(24H) 생성       5:5 가중평균 모델        조건 충족 시 주문


   1. 데이터 수집: 거래소 API를 연동하여 과거 2~3년치 1시간 봉(1H) 데이터를 다운로드합니다. (3년 기준 약 26,000줄의 최적의 데이터 규모 확보)
   2. 피처 엔지니어링 (Feature Engineering): 다운로드한 생(Raw) OHLCV 데이터를 AI가 학습할 수 있는 상대적 변화율과 6대 핵심 지표로 가공합니다.
   3. 모델 훈련 및 조합: 데이터를 학습용(80%)과 검증용(20%)으로 분할하여 두 모델을 각각 훈련시킨 후, 두 모델이 뱉어내는 상승 확률을 5:5로 평균 내는 앙상블 결합 레이어를 만듭니다.
   4. 실시간 실행 루프: 1시간마다(정각) 실시간 캔들 데이터를 받아 가공한 뒤, 모델에 입력하여 최종 상승 확률이 70% 이상일 때만 매수 주문을 발주하는 무한 루프 코드를 구동합니다.

------------------------------
## 3. 학습 입력 데이터(Feature) 구성 명세
머신러닝 모델은 숫자의 절대적인 크기에 영향을 받으므로, 가격 데이터를 그대로 넣으면 오작동합니다. 따라서 모든 가격은 '이전 캔들 대비 변화율'로 정규화하고, 핵심 지표 6개를 결합하여 총 10개의 가치 있는 입력 정보(Feature)를 구성합니다.
## A. 변환된 기본 OHLCV (4개)

* 
* 변환 고가 (High_pct): (현재 고가 - 현재 시가) / 현재 시가 ➡️ 당해 시간 내 상방 분출 강도
* 변환 저가 (Low_pct): (현재 저가 - 현재 시가) / 현재 시가 ➡️ 당해 시간 내 하방 눌림 강도
* 변환 종가 (Close_pct): (현재 종가 - 이전 종가) / 이전 종가 ➡️ 직전 대비 최종 수익률
* 변환 거래량 (Volume_pct): (현재 거래량 - 직전 20봉 평균 거래량) / 직전 20봉 평균 거래량 ➡️ 평소 대비 거래량 폭발 비율
* 

## B. 추천 핵심 기술적 지표 (6개)

   1. 볼린저 밴드 위치 (%B): 현재 종가가 볼린저 밴드 상단(1.0)과 하단(0.0) 사이에서 정확히 어느 위치에 있는지 나타내는 정규화된 수치 (상대적 위치 포착).
   2. RSI (14일 선): 단기 과매수/과매도 강도를 나타내는 절대 수치.
   3. MACD 히스토그램 기울기: MACD 본선과 시그널선의 차이(Histogram)가 최근 3개 캔들 동안 증가 추세인지 감소 추세인지의 변화량 (추세 에너지의 가속도 포착).
   4. 20일 이평선 이격도 (Disparity): 현재 가격이 20일 이동평균선과 몇 % 떨어져 있는지 계산 (과도한 이격에 따른 평균 회귀 타점 감지).
   5. 상대적 변동성 (ATR / Price): 현재 변동성(ATR)을 현재 가격으로 나눈 값 (시장이 숨죽이는 횡보 상태인지, 폭발 직전인지 AI에게 문맥 제공).
   6. 거래량 급증 비율: 최근 20개 캔들 평균 대비 현재 거래량의 멀티플 배수 (세력의 매집 및 거래량 동반 돌파 확인).

## C. 타임 윈도우(Time Window) 전략

* 
* 윈도우 크기: 1시간 봉 기준 과거 24시간~48시간이 가장 적당합니다.
* 반영 방식: 직전 캔들 3~5개는 위의 10개 지표를 시차 변수(Lag Feature)로 각각 펼쳐서 직접 입력하고, 그 이상 과거 데이터는 '24시간 최고가 대비 현재 위치', '24시간 평균 거래량 대비 비율' 같은 이동 평균(Rolling) 통계치로 압축하여 문맥을 제공합니다.
*

## 4. 운영 방식 및 리스크 관리 전략## A. 지표 변경 가이드라인

* 
* 확정된 지표 체계는 고정합니다. 위에서 정의한 10개의 피처 구조는 시스템의 '눈과 귀'에 해당하므로 임의로 자주 바꾸지 않습니다. 구조를 바꾸면 데이터 일관성이 깨져 AI가 시장을 해석하는 기준 뼈대가 무너집니다. [1] 
* 

## B. 주기적 모델 재학습 (Retraining)

* 
* 재학습 주기: 1주일 ~ 2주일 단위 필수 수행
* 이유: 크립토 시장은 '밈코인 불장', '거시경제 침체 하락장' 등 시장의 성격(Regime Shift)이 급격하게 변합니다. 구조(지표)는 그대로 유지하되, 최근 1~2주간 새로 발생한 최신 차트 데이터를 훈련 데이터셋 꽁무니에 붙여 모델의 가중치(Brain)를 주기적으로 업데이트해야 합니다. 그래야 AI가 현재 장세에 유리한 지표의 가중치를 스스로 갱신합니다.
* 

## C. 실전 구동 시 주의사항 (안전장치)

   1. 타임프레임 제한: 1분 봉/5분 봉은 노이즈가 너무 심해 과적합을 유발하고 수수료로 잔고가 녹아내리므로 절대 금지합니다. 안정적인 1시간 봉(1H)을 메인 타임프레임으로 사용합니다.
   2. 거래 비용의 엄격한 반영: AI 에이전트에게 백테스트 코드를 요청할 때 반드시 "왕복 수수료 최소 0.1%와 슬리피지(체결 오차) 마진을 차감하고 누적 수익률을 계산하라"고 명시해야 실전에서 계좌가 녹는 현상을 막을 수 있습니다.
   3. 인프라 환경: 초반에는 개인 PC로 모의 투자를 진행하며 검증하되, 실전 자동 매매 투입 시에는 인터넷 끊김이나 전원 종료 위험이 없는 월 1~2만 원 상당의 클라우드 가상 서버(AWS Lightsail 등) 환경으로 이식하여 24시간 중단 없이 구동하는 것을 권장합니다.
